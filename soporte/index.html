Suite Clínica Psiquiátrica (complemento de Google Docs™)

Escríbenos

Para dudas, problemas o sugerencias, escribe a simonmedinapsiquiatra@gmail.com. Respondemos en un plazo de 2 días hábiles (horario de Chile).

No envíes datos de pacientes (nombres, RUN, fichas ni capturas con información clínica real). Si necesitas mostrar un problema, usa datos ficticios.

Para reportar un error, incluye

  • Qué opción del menú usabas (p. ej. Planes Clínicos o Diagnóstico CIE-11).
  • Qué esperabas que pasara y qué pasó, con el texto exacto del mensaje de error si lo hubo.
  • El navegador y el sistema operativo.

Problemas frecuentes

No veo el complemento en el menú. Ábrelo desde Extensiones → Suite Clínica Psiquiátrica. Si acabas de instalarlo, recarga el documento.

Aparece «Se requiere autorización» o la ventana no abre. Si tienes varias cuentas de Google™ abiertas a la vez, cierra la sesión de las demás o usa una ventana de incógnito con una sola cuenta, y vuelve a abrir el complemento.

Quiero quitar el acceso. Desinstala el complemento desde Extensiones → Complementos → Administrar complementos o revoca los permisos en myaccount.google.com/connections.
